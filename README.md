# ТИУ Медиатека — фронтенд

Веб-интерфейс DAM ТИУ для бэкенда [tiu.media-hub](../tiu.media-hub/README.md): коллекции и права,
умный поиск (текст, фото, лицо), карточка материала с обсуждением и версиями, видео с участниками
и расшифровкой, редактор изображений, подборки, контент-порталы, справочник людей.

## Запуск

Нужны Node 22+ и запущенный бэкенд (`docker compose up -d` в tiu.media-hub).

```bash
cp .env.example .env
npm install
npm run dev            # http://localhost:5173, вход через Keycloak
npm run api:types      # перегенерировать типы после изменения API
npm run typecheck && npm run lint && npm run build
```

Dev-пользователи Keycloak: `ivanov/ivanov`, `petrova/petrova`, `admin/admin` (администратор).
В dev запросы `/api` идут через proxy Vite, поэтому CORS на бэкенде не нужен.

## Стек и решения

- React 19, TypeScript, Vite, SCSS Modules, Zustand, React Router (фильтры и поиск — в адресе).
- FSD: `app → pages → widgets → features → entities → shared`, границы проверяет ESLint.
  Внутри слайса — относительные импорты, между слоями — алиасы `@entities/...`, `@shared/...`.
- Запросы — через `BackendCaller` из `shared/api` прямо из stores и features, без отдельного API-слоя.
  Отдельные функции — только там, где это оправдано: загрузка файла (presigned PUT / multipart),
  публичный портал (токен `X-Portal-Token`), скачивание.
- Типы сущностей — алиасы на схему OpenAPI (`Schemas['AssetResponse']`), без ручного дублирования контракта.
- Вход — Keycloak, Authorization Code + PKCE (`keycloak-js`). Публичные порталы `/p/:slug` открываются
  без входа; сотрудник с активной SSO-сессией узнаётся тихо (`silent-check-sso.html`).
- Права (`read / write / manage / own`) приходят с сервера в ответах; UI только скрывает действия.
- Дизайн — макет Penpot «ТИУ DAM · Основные сценарии»: токены в `src/shared/styles/tokens.scss`,
  базовые компоненты — свой UI kit в `src/shared/ui` (общий API с другими фронтами). Только светлая тема.
- Шрифт — Inter Tight. Синий — действие и выбранное, фиолетовый — предложения AI, голубой — видеоразметка.

## Соответствие макета и API

- Статус «Можно публиковать / Нужна проверка» выводится из статуса лицензии на сегодня.
- Навигация собрана под бэкенд: коллекции плоские (вместо «Таксономии»), «Подборки» вместо «Избранного»,
  «Люди» и «Корзина» в рабочем пространстве. Квоты хранилища и уведомлений в API нет — в UI их нет.
- Видео: вкладки «Участники» (лица с таймкодами) и «Текст» (расшифровка); «Сцены» показаны как «скоро».
- Редактор: поворот шагом 90° и отражение (рецепт сервера не поддерживает произвольный угол),
  предпросмотр по превью совпадает с результатом по оригиналу — координаты в долях кадра.
- Списки — курсорная пагинация («Показать ещё») вместо номеров страниц.

## Известные ограничения

- «Недавние» хранятся локально в браузере (отдельно для каждого пользователя).
- Поиск коллег для выдачи доступа — только среди тех, кто уже входил в медиатеку.
- Ошибка рендера редактора сервером не видна: фронт ждёт результат до 90 секунд.
